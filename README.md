# e-plantShopping

## Paradise Nursery - Plant Shopping Cart Application

Paradise Nursery is a React-based e-commerce application for an online plant shop. This project allows users to browse a variety of houseplants organized into categories, view plant details such as images, names, descriptions, and prices, and manage a fully functional shopping cart.

### Features
- Landing page with a "Get Started" button
- Navigation bar with links to Home, Plants, and Cart
- Product listing page displaying plants grouped into multiple categories
- Add to Cart functionality with dynamic cart icon updates
- Shopping cart page with the ability to increase/decrease quantities, remove items, and view total costs
- State management implemented using Redux Toolkit

### Technologies Used
- React
- Redux Toolkit
- Vite
- CSS
